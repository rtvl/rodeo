## Download & Install

### Quick Download (Recommended)

**Download the ready-to-run app for your platform:**

📥 **[Download Latest Release](../../releases/latest)**

- **macOS**: Download the `.dmg` file, open it, and drag Rodeo to your Applications folder
- **Linux**: Download the `.AppImage` file, make it executable (`chmod +x`), and double-click to run
- **Windows**: Download the `.exe` installer and run it

### Building from Source

If you want to build Rodeo yourself, see [BUILD_EXECUTABLE.md](BUILD_EXECUTABLE.md) for detailed instructions.

Alternatively, check [bareback.s.yhat.com](http://bareback.s.yhat.com) for legacy releases.

## Getting Started

1. Download the app for your platform (see above)
2. Install/run the application
3. Start coding in Python with an IDE designed for data science!
